这三个接入入口有什么区别

直连直接访问 VPS 的协议监听端口。CDN 在前面代理 HTTP 流量，多个受支持协议共用 cdnym。Argo 由 cloudflared 主动建立隧道，本脚本一次绑定 vmpt、vwpt 或 xvargopt 中的一种。CDN 与 Argo 可以和其他直连节点并存。

参数标记：client 仅作用于客户端（用户本地端）；server 仅作用于服务端（VPS）。按本页配套配置标注，两端适用的参数不标记。客户端参数由 VPS 脚本写入配套链接或 JSON。两端适用不代表数值必须相同，具体匹配关系见字段说明。

没有匹配的协议。试试名称、核心名或端口变量。

Extra 与 FinalMask 默认关闭。开启后载入对应协议的默认方案；展开“自定义”可调整子模块和参数，各协议独立保存。

02出站

分配 A → B1、B2 等出站路径

默认直连。每个入站最多分配一个二级代理。同一入站协议的流量已配置经所属核心的 WARP 出站时，须先取消该 WARP 出站才能选 B。不同入站可分别分配给 B1–B16。URL 中的 WireGuard 上游独立于 Cloudflare WARP 出站。

每组填写独立完整链接，编号可跳过。普通代理把目标域名交给 B 解析；WireGuard 上游的目标 DNS 经隧道。目标解析失败不回退到 A 直连查询。B 自身域名保留动态解析，其连接所需的引导查询独立留在 A。A 的核心能够完整承载参数时优先原生连接 B，否则经本机 Sing-box 转接，最终由 VPS 校验。Mita 对允许目标 UDP 的 SOCKS5 上游优先原生连接，其他情况经本机 Sing-box；Naive 的 Caddy 仍经本机 Sing-box，仅承载目标 TCP。第三方节点的 DNS、UDP 支持和访问限制由供应商决定。SOCKS 的 udp=0 仅转发目标 TCP；SS UoT 需要 B 支持 v2。现有二级出站不会随脚本更新自动迁移。

03证书与订阅

证书、地址与订阅

统一配置节点证书、系统 IP 策略与 HTTPS 订阅。

REALITY无需申请 CA 证书。

HTTPS 订阅必须使用 CA，优先复用；没有则申请。

NaiveProxyCaddy 自动申请并管理域名证书。

自签证书只用于未开启订阅的普通 TLS 节点，需要客户端建立信任或固定指纹；HTTPS 订阅不接受自签证书。SS / SOCKS5 入口仅在终端输出完整 URL，不加入订阅。VLESS Encryption 节点请使用完整 URL 或聚合订阅，脚本不会生成缺失加密参数的 Clash 节点。

更多变量：证书账户、跳跃端口与源地址
