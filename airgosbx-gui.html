01协议与接入

选择协议与接入方式

可以组合多种协议。端口留空使用脚本默认的随机分配。

0 个已选
这三个接入入口有什么区别

直连直接访问 VPS 的协议监听端口。CDN 在前面代理 HTTP 流量，多个受支持协议共用 cdnym。Argo 由 cloudflared 主动建立隧道，本脚本一次绑定 vmpt、vwpt 或 xvargopt 中的一种。CDN 与 Argo 可以和其他直连节点并存。

没有匹配的协议。试试名称、核心名或端口变量。

Extra 与 FinalMask 默认关闭。开启后载入对应协议的默认方案；展开“自定义”可调整子模块和参数，各协议独立保存。

02出站

选择出站路径

默认直连。WARP 可与二级代理并用，选入 secp 的协议优先走 B 服务器。

哪些协议走 B

Mieru/Mita 不支持当前 secp 路径。Naive 需单独选中，并通过本地 Sing-box 转交；选择 Naive 或 Sing-box 协议时，B 地址必须是 IP。

03证书与订阅

证书、地址与订阅

统一配置节点证书、系统 IP 策略与 HTTPS 订阅。

REALITY无需申请 CA 证书。

HTTPS 订阅必须使用 CA，优先复用；没有则申请。

NaiveProxyCaddy 自动申请并管理域名证书。

自签证书只用于未开启订阅的普通 TLS 节点，需要客户端建立信任或固定指纹；HTTPS 订阅不接受自签证书。VLESS Encryption 节点请使用完整 URL 或聚合订阅，脚本不会生成缺失加密参数的 Clash 节点。

更多变量：证书账户、跳跃端口与源地址
